# 0.8.1 findings ledger

One row for every finding the 0.8.1 hotfix branch closes: the finding, the commit that closes it and
the test that covers it. There was no earlier place in the repository for review records, so this
directory holds them.

Finding ids T1 to T4, S1, S3, E5, E6, E8, Q4, X1 and P2 come from the integrated review of 0.8.0
(three independent reviews; each finding was checked by reading or running the code at `d1d2abe`).
Rows `B1` to `B6` come from an independent review of this branch. Severity is the integrated
review's, where it gave one. Status: **fixed** closes the finding; **stopgap** removes the unsound
claim now and leaves the full fix to 0.9.0.

Mutation checks (one guard undone at a time, the named test must fail) were run for the packages
before B1: 32 of 36 mutations were caught. The four survivors are redundant guards: the explicit
`..` test in `contained_path` (the resolved-path check repeats it), a cap on the number of runs in
the pairing helper (its callers cap it too), the outer budget check before minimization (the check
inside it repeats it), and a sum check in the float matching (an earlier group-size check implies
it). For the minimization guard of the agents pack, a run limit is also enforced by `_runs_left`;
money and time limits are covered by `tests/test_budget_all_runs.py`.
